## Disease Identification Quick Guide

### Visual Symptom Matching

#### **Yellowing Leaves?**
- **Orange to yellow discoloration → TUNGRO** (+ stunted growth)
- **Yellow from leaf tip/margin → BACTERIAL BLIGHT** (+ water-soaked streaks)
- **Yellow halos around brown spots → BROWN SPOT** (+ small round spots)

#### **Leaf Spots/Lesions?**
- **Spindle/diamond-shaped → LEAF BLAST** (gray center, brown edges)
- **Brown circle/oval like sesame → BROWN SPOT** (yellow halo)
- **Tiny black powder-like → LEAF SMUT** (pepper dust appearance)

#### **Plant Appearance?**
- **Much smaller/stunted → TUNGRO** (+ yellow/orange leaves)
- **Normal size but infected → LEAF BLAST, BROWN SPOT, LEAF SMUT**
- **Wilting/dying → BACTERIAL BLIGHT** (especially seedlings)

## Root Cause Identification

### **I see Yellowing Leaves Starting from Tips:**
→ **Likely: BACTERIAL BLIGHT**
- Check for water-soaked streaks
- Look for bacterial ooze (milky drops)
- Check seedlings (kresek symptoms?)
- Root cause: Bacteria in water/air, high humidity, excess nitrogen

### **I see Brown Spots with Yellow Halos:**
→ **Likely: BROWN SPOT**
- Are plants weak/nutrient-deficient?
- Recent drought stress?
- Soil potassium levels low?
- Root cause: Low potassium, drought stress, poor soil fertility

### **I see Diamond-Shaped Lesions with Gray Centers:**
→ **Likely: LEAF BLAST**
- Are many leaves affected?
- Is field humid and wet?
- Are lesions increasing rapidly?
- Root cause: High humidity, wet conditions, excess nitrogen

### **I see Tiny Black Pepper-Dust Spots:**
→ **Likely: LEAF SMUT**
- Spots on both leaf sides?
- Not merging together?
- Mostly on older leaves?
- Root cause: High nitrogen, humid conditions, poor sanitation

### **I see Orange/Yellow Stunted Plants + Leafhoppers:**
→ **DEFINITELY: TUNGRO** ⚠️
- IMMEDIATE ACTION NEEDED
- Remove infected plants NOW
- Control leafhopper population
- Root cause: Virus + insect vector

## When to Call Agriculture Expert

### ⚠️ CALL IMMEDIATELY
- **Tungro**: Many plants showing symptoms in 5-7 days
- **Bacterial Blight**: Large patches of yellowing plants
- **Leaf Blast**: Lesions appearing daily on multiple leaves

### ⚠️ CALL WITHIN 3-4 DAYS
- **Brown Spot**: Spots on >20% of plants
- **Leaf Blast**: Symptoms increasing after rain
- **Bacterial Blight**: Symptoms spreading to new areas

### ⚠️ CALL WITHIN 1-2 WEEKS
- **Brown Spot**: Nutrient deficiency suspected
- **Leaf Smut**: Severe infection developing
- **Any disease**: Unsure about treatment recommendation

### **Don't Wait - Always Consult If:**
- Disease identification uncertain
- 10%+ of plants affected
- Symptoms spreading rapidly
- Unsure about chemical safety
- Need local product recommendations

## Fertilizer Guidance by Disease

### **Bacterial Blight: Managing Nitrogen**
```
Problem: Excess nitrogen causes WORSE disease
Solution: 
- Reduce nitrogen application by 25%
- Use balanced 16:16:16 NPK instead of high-N
- Apply in split doses (not all at once)
- Ensure adequate potassium (K ratio)
Impact: Can reduce disease by 30-40%
```

### **Leaf Blast: Balanced Nutrition**
```
Problem: Excess nitrogen in dense canopy = high humidity
Solution:
- Use balanced or slightly low-N fertilizer
- Apply silicon fertilizer (calcium silicate)
- Split applications (2-3 times, not once)
- Adequate potassium essential
Impact: Reduces lesion development significantly
```

### **Brown Spot: Potassium Priority**
```
Problem: Low potassium = WEAK plants = more disease
Solution:
- Test soil potassium FIRST
- Apply potassium-rich fertilizer (K > N)
- Use balanced or high-K NPK
- Apply calcium silicate
Impact: Can reduce disease by 50%+ if K was deficient
```

### **Tungro: Don't Attract Pests**
```
Problem: Excess nitrogen = more leafhoppers
Solution:
- Use balanced NPK only
- Avoid nitrogen spikes
- Apply adequate potassium
- Don't over-fertilize (attracts insects)
Impact: Fewer leafhoppers = less virus spread
```

### **Leaf Smut: Simple Nutrition**
```
Problem: High nitrogen in humid field = spore production
Solution:
- Balanced NPK sufficient
- Avoid excessive nitrogen
- Normal fertilization schedule
Impact: Prevents ideal conditions for disease
```

## Temperature & Weather Timing

### **Favorable Timing for Diseases (When Most Likely)**

**Bacterial Blight**
- When: Temperature 25-34°C + heavy rain
- Where: High rainfall areas
- Action: Increase monitoring during rainy season

**Leaf Blast**
- When: Temperature 24-28°C + frequent wet
- Where: Upland/temperate areas
- Action: Monitor closely from head emergence onward

**Brown Spot**
- When: Any temperature (16-36°C possible)
- Worse: Under drought stress OR excess moisture
- Action: Maintain proper irrigation

**Tungro**
- When: High leafhopper populations
- Where: Continuous cropping areas
- Action: Scout daily, remove early infections

**Leaf Smut**
- When: Humid, warm conditions
- Slower: Cool, dry weather
- Action: Routine monitoring sufficient

## Emergency Response Protocol

### **IF YOU SEE TUNGRO SYMPTOMS:**
```
⏰ TIMELINE: ACT WITHIN HOURS
1. IMMEDIATELY remove infected plants (pull out completely)
2. Place in sealed bag (prevent insect escape)
3. BURN or DEEP BURY (don't compost)
4. Contact local agriculture office TODAY
5. Inform neighboring farmers IMMEDIATELY
6. Start leafhopper spraying if recommended
```

### **IF YOU SEE RAPID BACTERIAL BLIGHT SPREAD:**
```
⏰ TIMELINE: ACT WITHIN 1-2 DAYS
1. Stop all irrigation for 2-3 days (reduce spread)
2. Improve field drainage NOW
3. Scout entire field for extent
4. Remove severely infected plants if <10%
5. Contact agriculture office for bactericide
6. Prepare fungicide for secondary infections
```

### **IF YOU SEE RAPID LEAF BLAST SPREAD:**
```
⏰ TIMELINE: ACT WITHIN 1-2 DAYS
1. Confirm identification with expert
2. Prepare fungicide application
3. Scout field daily for new lesions
4. Improve field ventilation (remove obstacles)
5. Check fungicide recommendations with local office
6. Apply fungicide at proper timing
```

## Economic Decision Making

### **Cost-Benefit Analysis Example**

**Bacterial Blight in 1 hectare field:**
```
Each 10% yield loss = ~500 kg loss = 5,000-7,500 PHP loss
Management costs per application = 500-1,000 PHP
If management prevents 20% loss = Savings of 10,000-15,000 PHP
ROI: 10-20x investment worth spending
```

**Tungro in infected field:**
```
Complete crop loss = 50,000 PHP+ loss
Prevention cost = 5,000-10,000 PHP in resistant varieties
Leafhopper control = 2,000-3,000 PHP
ROI: PREVENT AT ALL COSTS (essential)
```

**Brown Spot with nutrient deficiency:**
```
Field soil test = 500 PHP
Potassium application = 3,000-5,000 PHP
Fungicide (if needed) = 2,000-3,000 PHP
Prevention of 30% loss = Savings of 15,000+ PHP
ROI: Prevention is economical
```
